数据：QASPER v0.3，100 篇全文、100 条官方文本证据问题；已知目标论文范围。
四组使用同一语料、问题、BGE 分词与 30 候选预算；未按测试结果调参；无付费 API 调用。

- hybrid_minus_dense: +0.30 个百分点；按论文聚类的配对 bootstrap 95% 百分位区间 [-7.40, +6.95]。

限制：英文单轮、已知论文、段落覆盖代理指标；任一滑窗命中计作对应段落被召回，不保证完整答案证据覆盖。
