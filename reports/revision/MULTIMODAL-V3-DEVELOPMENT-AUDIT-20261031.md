# V3 开发复验：独立 agent 引用与原页核查

本报告核查旧的 ELMo / Sentence-BERT 诊断题在 `runs/multimodal-diagnostic-v3-20261031/`、`runs/multimodal-diagnostic-v3-decomposed-20261031/`、`runs/multimodal-numeric-repair-dev-20261031/` 和 `runs/multimodal-numeric-repair-dev-v2-20261031/` 的实际输出及相关本地 `claim-audit`。复核者未参与实现或模型调用，是另一 agent；**不是人工核查，也不是盲审**。该旧题集已用于开发，以下均为定向开发复验，不能当作新的论文隔离保留集首轮成绩。未查看新的保留集检索或问答输出，未修改代码、题集或调用模型。

核查方法：以原始 PDF 物理页、原页渲染及实际被引局部文本 / 裁图为准；把回答事实、引用键是否合法、位置是否对应、每条声明是否由所引区域支持分开。这里根据实际结果中的证据目录与页、框、来源 ID 交叉检查位置，并不以本报告代替程序端完整引用合法性审计。经本地 SHA-256 核对，D19 Figure 1、Figure 2 和 N18 Table 1 三张实际引用裁图分别与结果中保存的图像哈希一致；哈希一致本身不证明视觉或语义正确，另已对照原页查看。

## 分解运行的 h09 与 h12

`multimodal-diagnostic-v3-decomposed-20261031` 的 h09 回答 ELMo 是上下文相关词级表示、SBERT 是句子级嵌入，分别引用 N18 第 1 页 `v-44927d29ed8f004f00913840` 和 D19 第 1 页 `v-9a9b892764a8e2dc0b87af34`；原文分别支持对应说法。该运行虽然选入并引用了 D19 摘要，但 D19 摘要在 `fused_refs` 第 7、**不在最终 Top-5**；不能把完整证据送入模型或答对等同于两条目标都进入 Top-5。

同一分解运行的 h12 作出六条声明：D19 图形、图注和正文分别支持架构、推理用途和余弦计算；N18 图注与正文分别支持不同任务及 ELMo 位置的 softmax 归一化层权重；最终归属声明同时引用 D19 图形/图注/正文与 N18 图注，原页支持在这两篇中选择 Sentence-BERT。两论文 Figure 2 图框在最终 Top-5（D19 第 1、N18 第 4）；扩展正文和图注有各自独立引用位置。六条同模型 verdict 为 supported，只算该模型的检查，不是独立事实证明。

## h07 数值修复的两次开发尝试

1. `multimodal-numeric-repair-dev-20261031`：初始 `bert_time` 引用的摘要后段不含其 10,000 条件，数值检查记录 missing；修复响应只给出了未补齐引用的 `bert_time`，被记录为 rejected，最终 `numeric_citation_incomplete` 受控拒答。该次保留原始三条生成声明、修复响应和拒答原因；没有可当作已通过的最终回答，也没有逐条自检 verdict。
2. `multimodal-numeric-repair-dev-v2-20261031`：初始 `bert_time` 同样缺少 10,000 的引用。修复后第一条同时引用摘要后段 `v-9a9b...` 与前段 `v-f7ae...`：前段包含 10,000 和约 65 小时，后段有 65 小时与 5 秒，第一条的数字和数量条件得到联合支持。第二条为“this ... 约 5 秒”，只引摘要后段；结合前一条及全部答案引用可理解为同一 10,000 句任务，但如果按**每条声明及其自带引用独立核查**，这一隐含数量条件仍需回看前一声明的引用。该结果是整段答案联合证据支持，不能不加限定地说第二条声明的单条引用自包含全部条件。两条最终同模型 verdict 为 supported，只是辅助检查。

第二次运行的 `claim-audit` 的 `citation_repair.response` 和最终 predictions 包含新增的 `v-f7ae...` 引用；但该审计文件的 `cited_regions` 仅列原来 `v-9a9b...` 的位置，新增区域的页码和 bbox 需再从最终 `predictions.json` 或可信语料取回。故目前能跨本地文件追溯，不能宣称该单个审计文件独立保存了修复后所有引用定位。事实正确、数值字符串覆盖、引用位置存在与语义完全支持须分别检查。

主线程随后新增只读后处理结果 `runs/multimodal-numeric-repair-dev-v2-20261031/joined-claim-audit.json`，将原始、修复及最终引用的 ID 与各自来源页码、bbox 合并，原模型结果与原 `claim-audit` 均保留。该合并改善了跨文件定位，不是另一次模型复验或语义核验，也不改变上面对第二条隐含数量条件的限制。

本审查未穷尽其他页面、所有候选或者图注关系；除上述明确核查范围以外，关联与语义保持 unknown。所有案例及本报告仍需独立人工复核。
