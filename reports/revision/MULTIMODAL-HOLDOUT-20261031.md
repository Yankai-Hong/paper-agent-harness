## 实现与真实环境

Docling 多 provenance 正文按有效、无非空缺口的字符区间拆分；区间重叠、缺失或无法证实的文本保持 unknown，不以整段文本伪装到每一个区域。视觉多区域单独保留分组关系和原坐标，图注仅使用可验证的 Docling 关联；表格导出结构化文本但标记未经核实。90 度旋转为显式选项，其他角度仍需另行验证。

新增独立 BGE 图注及表格文本索引，同现有 BM25+BGE 正文、CLIP 图像各自检索并融合；原始问题和安全改写均保留，候选、范围与路线可追踪。向量空间没有混合。开发论文的真实本地 BGE 索引含 28 条图注和 21 条表格文本，两类真实检索均返回五个候选；此 smoke test 不等于保留集效果。

既有 `.venv-mm-20261030` 为 Python 3.10.11、Docling 2.48.0、Sentence Transformers 3.4.1、FAISS CPU 1.9.0.post1、PyTorch 2.6.0+cu124；证书验证保持开启。当前受限命令环境不能初始化 `_ssl`，同一解释器在正常系统权限下可用 OpenSSL，未通过关闭校验解决。两篇保留论文均由 Docling 在 CUDA 上运行：ELMo 174 条、9 个视觉区域、10 组多区域拆分；Sentence-BERT 166 条、9 个视觉区域、11 组拆分。合并后为 322 条正文、18 个图表。初步检查发现 ELMo 第 5 页 Table 1 的裁剪存在，但图号未识别，保持 unknown；按图号过滤可能漏掉它，不在保留集执行过程中针对该结果修改实现。

执行用 BGE 和重排器 CPU、CLIP GPU；模型均为原有快照。单次生成上限 1024 token、60 秒、无自动重试。新运行单独建立逐请求本地账本，不修改旧账本，发送前预留；仅对生成与逐项自检保存通过敏感内容检查的响应，图片、请求体和密钥不写入该账本，外部遥测关闭。同模型自检不等于独立语义核验。

冻结前多模态相关测试 35 passed；全量测试 326 passed、1 skipped、73 warnings，日志 `output/mm-holdout-full-tests.log`。这证明回归状态，不能代替真实语义评价。

## 保留集结果

13 条问题和 3 条图搜图均已执行。原始 Top-5、失败和回答保存在 `runs/multimodal-holdout-v1-eval-20261031/predictions.json`，逐请求记录保存在其 `requests/` 下；三个图搜图目标均为第 1 位。另一 agent 的[逐声明、引用区域与完整图搜图结果复核](MULTIMODAL-HOLDOUT-RESULT-AUDIT-20261031.md)支持下表结论；该 agent 未参与实现或模型调用，但曾复核题集且可见上下文，并非盲审。没有独立人工复核。
