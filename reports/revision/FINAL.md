## 回归与真实服务

最终 `python -m pytest -q --junitxml=reports/revision/final-v2-tests.xml`：**151 passed，73 warnings，15.98 秒**。包含迁移重复执行与备份回滚、旧会话恢复、隔离/共享、冲突/更新/删除、Redis 过期模拟、Chroma 真实部分损坏修复、提交失败与两个子进程崩溃、拆分越权、超预算、遥测故障、HTTP 错误分类和半开状态。[测试日志](final-v2-tests.log)。回归需要可访问本机临时 HTTP 端口；在受限环境下的 PermissionError 与获许可后的通过结果分开保留。

真实组件集成（固定回答器、无模型 API）：真实 BGE-M3/FAISS、Cross-Encoder、Redis、SQLite、Chroma 六轮；TTL过期恢复、幂等重放、情景索引部分删除和重建通过。[结果](integration-final-v2/result.json)。本次 Redis 用隔离端口16487，测试后关闭；原有 Redis 未启动造成的首轮失败保留在 [integration-v1](integration-v1/result.json)。真实模型质量不能从固定回答器通过推断。

## 数据迁移

21个旧 SQLite 评测库共922条旧事实：904条 paper_evidence、18条用户显式评测声明。确认其为历史评测数据后在独立目标迁移并复跑：94会话、54事件、12声明迁入；904论文证据及6条未确认/旧版本留在只读备份，不参与新系统活跃召回。源库哈希未变；逐库结果、备份和遗漏见 [迁移清单](migration-inventory-v2.json)。

另发现 runs 下46对独立旧历史/记忆 JSON，合计483个旧事实条目（可能重复），归属尚未逐一确认；92个文件已只读备份，46个会话未自动导入，详见 [文件盘点](file-memory-inventory.json) 与 [备份清单](file-migration-inventory.json)。确认归属后用新空目标执行迁移；未知归属不会自动晋升。可操作回滚命令见 [记忆文档](../../docs/memory.md)，保留新版数据后在独立目录恢复旧备份。

## 限制与展示判断

- 真正的 Langfuse 实例和 SDK 服务端读回未验收；[官方兼容说明](https://langfuse.com/docs/compatibility) 指出 Python SDK v5 需要 Python 3.11+，本机仍是 Python 3.10，适配器限定 v4，不升级环境。实际自建服务版本须另行核对。
- 没有能力验证独立备用模型，主备切换未实现；本机命名空间不能代替用户认证，跨进程熔断未实现。系统不保证在底层 GPU/DNS 调用中强制中断墙钟超时。
- 自然语言引用约束、推理正确性及生成内容的语义支持仍需更大固定样本与独立人工评审；用户规则可能漏识别自然表达。对旧无账本摘要和归档保持保守边界。
- 适合展示可审计的研究型工程、数据迁移与故障恢复；不能宣称论文级效果提升、通用个人记忆正确率、真实 Langfuse 验收或生产级高可用。真实/模拟/未验证情况须随演示一同说明。
