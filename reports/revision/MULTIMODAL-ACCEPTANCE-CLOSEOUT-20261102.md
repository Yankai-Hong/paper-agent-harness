## 具体修复及验证

- **v308 论文范围与首页证据**：对普通“论文 ID 的标题和作者”形式，仅在本地目录存在唯一字面 ID、NLU 范围一致、没有历史或多论文歧义且原首页有唯一有效标题块时，加入可定位标题与相邻候选文本；作者身份仍需证据判定。目录外 ID 和 NLU 返回未知 ID 均受控澄清；歧义及历史指代不强行套入。数值守卫只排除与已引用来源相同的**完整论文 ID**，不会忽略独立年份、数值或单位。最终源码单题 `runs/multimodal-acceptance-v308-v5-20261102/`：BART 首页标题块 `v-8b5eae33d2488c0053126e62`、署名块 `v-1ddb443c2b36c90376d92bc3` 分列 Top-5 第 1、2；回答完整标题与首位 Mike Lewis，独立 agent 对照 p1 支持。标题元数据仍标 unverified，不能作为局部框内原文。

- **v301 阶段完整性**：生成提示要求多阶段回答包含证据中区分各阶段的领域、数据和目标；有界的第二次 Reflect 检查实际保留声明是否覆盖问题，不自动添加答案。v3 回答说明通用领域预训练、目标任务 LM 微调、目标任务分类器微调，并引用 ULMFiT p3 的图/图注；原页复核支持。但同一完整性检查未发现 v305 漏限定，不能宣称这一机制保证全面完整。
